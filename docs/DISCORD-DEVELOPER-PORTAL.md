| --- | --- |
| Terms of Service URL | `https://nexus-website-1406.onrender.com/terms` |

Persian versions are also available:

- Terms of Service: `https://nexus-website-1406.onrender.com/terms?lang=fa`
- Privacy Policy: `https://nexus-website-1406.onrender.com/privacy?lang=fa`

## Before submitting

1. Open both canonical English URLs in a private browser window.
2. Confirm each page loads over HTTPS without authentication.
3. Verify the page title, effective date, content, and navigation.
4. Use the language switch to confirm the Persian version is readable and right-to-left.
5. Confirm `/healthz` returns HTTP 200 and JSON status `ok`.
6. Paste the English URLs into the matching Discord Developer Portal fields and save.

The website uses `noindex` directives to discourage search indexing. This does not make the pages private or block Discord's HTTP access.
